# Assignment 2: Difference Between Structured Dataset and Unstructured Dataset

## Introduction

- **Structured Dataset** is data organized in a fixed format of rows and columns, following a predefined schema.
- **Unstructured Dataset** is data with no fixed format or schema, such as text, images, audio, and video.


## Comparison Table

| #  | Basis            | Structured Dataset                                             | Unstructured Dataset                                                 |
| :-: | ---------------- | -------------------------------------------------------------- | -------------------------------------------------------------------- |
| 1  | **Definition**   | Data organized in a predefined format with rows and columns.   | Data that does not follow a predefined format or structure.          |
| 2  | **Organization** | Highly organized and arranged systematically.                  | Not organized in a fixed tabular format.                             |
| 3  | **Format**       | Usually stored in tables with rows and columns.                | Stored as text, images, audio, and videos.                           |
| 4  | **Schema**       | Follows a predefined schema.                                   | Does not follow a fixed schema.                                      |
| 5  | **Storage**      | Relational databases (MySQL, PostgreSQL).                      | File systems, data lakes, and NoSQL databases.                       |
| 6  | **Processing**   | Easy to process and analyze using traditional tools.           | Requires specialized tools and techniques.                           |
| 7  | **Querying**     | Easily queried using SQL.                                      | Difficult to query directly using traditional SQL.                   |
| 8  | **Examples**     | Student records, employee details, bank transactions, etc.     | Images, videos, audio recordings, emails, social media posts, etc.   |

---

## Conclusion

> **Structured data is easy to store and query; unstructured data is harder to handle but far more common.**
> Structured data fits neatly into tables and SQL. Unstructured data needs specialized tools, such as NoSQL databases and machine learning, to extract value from it.
